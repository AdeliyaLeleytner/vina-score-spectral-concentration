# Data licenses

The MIT `LICENSE` applies to software and documentation written for this repository. It does
not override upstream data licenses. `data_manifest.csv` is the machine-readable authority
for each frozen input.

- Author-generated docking matrices, rescoring tables, target-family annotations, pocket
  descriptors, and analysis summaries are released under CC BY 4.0 unless a stronger
  upstream share-alike condition applies.
- ChEMBL release 34 data and derived tables are distributed under CC BY-SA 3.0. ChEMBL must
  be attributed when these files are reused.
- The DOCKSTRING v1 score table retains its Figshare Apache-2.0 license and source DOI,
  `10.6084/m9.figshare.16511577.v1`.
- wwPDB source structures are available under CC0 1.0; the compact author-derived pocket
  descriptor table is released under CC BY 4.0.
- The author-prepared DAVIS processed export and DTI summary are released under CC BY 4.0;
  reuse must also cite the original DAVIS dataset and the model/data sources documented in
  `PROVENANCE.md`.

The frozen files are included to permit third-party verification without registration. No
license or authorship is assigned to software assistants used during manuscript editing.
