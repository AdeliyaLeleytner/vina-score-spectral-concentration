# Operational ranking row-mean-panel sensitivity

This directory contains the one-factor sensitivity generated by
`analysis/ranking_centering_panel_sensitivity.py`.

- `summary.json` is the machine-readable result and inference contract.
- `ligand_sensitivity.csv` records row means, coverage, pair-prediction changes,
  and representation-specific per-ligand accuracies for all 137 evaluation
  ligands.

The two arms differ only in the targets used to calculate each evaluation
ligand's row mean: all 44 Docking-44 targets or the 38 targets present in the
fixed operational benchmark. Missing-score imputation means, target offsets,
the grand mean, and target-specific residual scales are estimated once from the
12,514 reference ligands after excluding all evaluation ligands and are held
fixed. The local-38 arm is therefore not a separately refitted normalization.

The all-44 representation reproduces the released benchmark accuracy
(0.5639355481). The local-38 accuracy is 0.5669823647, a paired difference of
0.0030468166. Only 31 of 2,522 eligible experimental target-pair predictions
(1.23%) change, across 19 ligands. The Murcko- and Butina-cluster 95% bootstrap
intervals for the local-38-minus-all-44 difference both include zero.
