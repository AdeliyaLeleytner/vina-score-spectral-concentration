# Docking-44 Vina numerator and torsion audit

This directory is generated by:

```bash
cd jcheminf_dimensionality
.venv/bin/python analysis/docking44_vina_numerator_audit.py
.venv/bin/python analysis/test_docking44_vina_numerator_audit.py
```

The analysis compares the frozen normalized Vina score with the summed
per-residue intermolecular-energy numerator and two ligand-specific torsional
normalizations. Every comparison preserves the frozen scalar matrix's missing
and zero-censoring mask before target-mean imputation and column
standardization.

## Non-negotiable support boundary

The result uses the exact 43-target overlap. `V1A` is excluded because no exact
`V1A_residue_matrix.csv` exists. `9uwl_residue_matrix.csv` is not substituted:
the frozen scalar table has no `9uwl` score column, and substituting it would
silently join different data keys.

The residue row sums are derived upstream artifacts, not a lossless pose-level
decomposition. The inferred factor `q_i = median_j(E_ij/S_ij)` is consequently
a diagnostic reconstruction and is circular with respect to the scalar scores.
The independently specified `1 + 0.05846 * rotatable_bonds` surface is reported
as a separate ligand-descriptor sensitivity. The q-shuffle is descriptive; it
is not a biological null or an inferential p-value.

Two q-shuffles are retained. A global shuffle lowers residual PR, whereas a
shuffle within exact RDKit heavy-atom counts does not. The global contrast
therefore mainly reflects association between the flexibility factor and
molecular size; it is not evidence for finer within-size alignment with target
residuals.

## Outputs

- `analysis_summary.json`: support contract, headline results, factor and
  reconstruction diagnostics, q-shuffle summary, and the additive-model rank
  bound.
- `surface_metrics.csv`: raw and two-way-centered PR values on primary and
  complete-case supports.
- `q_factors.csv`: inferred and descriptor-based ligand factors.
- `q_shuffle_null.csv`: all seeded ligand-factor permutations.
- `target_reconstruction.csv`: target-wise reconstruction correlations/errors.
- `target_reconstruction_leave_one_out.csv`: each target reconstructed with a
  ligand factor estimated only from the other 42 targets.
- `input_manifest.csv`: exact input paths, shapes, sizes, and SHA-256 digests.

The algebraic control is

```text
H_N D E H_P = H_N D Gamma H_P + (H_N D 1)(b^T H_P),
```

for `E = a 1^T + 1 b^T + Gamma`. Therefore, applying a common row factor to a
purely additive numerator creates only one centered mode; it cannot by itself
explain a residual PR near nine.
